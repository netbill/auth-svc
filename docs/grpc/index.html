UserService

UserService manages users: registration, profile, credentials.

All methods except CreateUser require authentication via metadata:

authorization: Bearer

Method NameRequest TypeResponse TypeDescription
CreateUser CreateUserRequest CreateUserResponse

CreateUser registers a new user. Errors: ALREADY_EXISTS — email is already taken INVALID_ARGUMENT — password does not meet requirements
GetMyUser GetMyUserRequest GetMyUserResponse

GetMyUser returns the authenticated user's profile. Errors: NOT_FOUND — user does not exist or was deleted
GetMyEmail GetMyEmailRequest GetMyEmailResponse

GetMyEmail returns the authenticated user's primary email address. Errors: NOT_FOUND — user does not exist
UpdatePassword UpdatePasswordRequest .google.protobuf.Empty

UpdatePassword changes the password of the authenticated user. The old password must be provided for verification. Errors: UNAUTHENTICATED — old password is incorrect or session is invalid INVALID_ARGUMENT — new password does not meet requirements FAILED_PRECONDITION — password was changed too recently
DeleteMyUser DeleteMyUserRequest .google.protobuf.Empty

DeleteMyUser soft-deletes the authenticated user along with all its sessions and email addresses. The operation is irreversible via the API. Errors: UNAUTHENTICATED — session is invalid or expired

SessionDeletedFilter

SessionDeletedFilter filters sessions by their deletion status.

NameNumberDescription
SESSION_DELETED_FILTER_ALL 0

Return both active and deleted sessions. Default.
SESSION_DELETED_FILTER_ACTIVE 1

Return only active (non-deleted) sessions.
SESSION_DELETED_FILTER_DELETED 2

Return only deleted (terminated) sessions.

SessionLastUsedOrder

SessionLastUsedOrder controls the sort direction of the last_used field.

NameNumberDescription
SESSION_LAST_USED_ORDER_DESC 0

Most recently used first. Default.
SESSION_LAST_USED_ORDER_ASC 1

Least recently used first.

SessionService

SessionService handles authentication: login, token refresh, session management.

Login and Refresh methods are public (no token required).

All other methods require authentication via metadata:

authorization: Bearer

Method NameRequest TypeResponse TypeDescription
LoginByEmail LoginByEmailRequest LoginResponse

LoginByEmail authenticates a user by email and password. Returns a token pair on success. Errors: UNAUTHENTICATED — email not found, user deleted, or password is incorrect
LoginByGoogle LoginByGoogleRequest LoginResponse

LoginByGoogle authenticates a user via a Google ID token. The user must already exist with the email from the Google token. Errors: UNAUTHENTICATED — user with this email not found or deleted
Refresh RefreshRequest LoginResponse

Refresh exchanges a valid refresh token for a new token pair. The old refresh token is invalidated after a successful call. Errors: UNAUTHENTICATED — refresh token is expired, invalid, mismatched, or session not found
GetMySession GetMySessionRequest GetMySessionResponse

GetMySession returns a specific session belonging to the authenticated user. Errors: INVALID_ARGUMENT — session_id is not a valid UUID NOT_FOUND — session not found or does not belong to this user
GetMySessions GetMySessionsRequest GetMySessionsResponse

GetMySessions returns a paginated list of sessions for the authenticated user. Supports filtering by active/deleted status and sorting by last_used timestamp. Errors: INTERNAL — unexpected server error
Logout LogoutRequest .google.protobuf.Empty

Logout terminates the current session. If the session is already terminated, the call succeeds without error. Errors: INTERNAL — unexpected server error
DeleteMySession DeleteMySessionRequest .google.protobuf.Empty

DeleteMySession terminates a specific session belonging to the authenticated user. Errors: INVALID_ARGUMENT — session_id is not a valid UUID NOT_FOUND — session not found UNAUTHENTICATED — session does not belong to this user
DeleteMySessions DeleteMySessionsRequest .google.protobuf.Empty

DeleteMySessions terminates all sessions of the authenticated user. Errors: UNAUTHENTICATED — session is invalid or expired

AuthService

AuthService is an internal service used by other microservices to validate

incoming access tokens and retrieve the associated user and session.

Authentication: pass the access token via metadata:

authorization: Bearer

Method NameRequest TypeResponse TypeDescription
ValidateSession ValidateSessionRequest ValidateSessionResponse

ValidateSession parses the access token from metadata, verifies it against the database and returns the full user and session objects. Errors: UNAUTHENTICATED — token is missing, invalid, expired, or the session/user was deleted after the token was issued INTERNAL — unexpected server error
